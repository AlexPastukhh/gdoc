# Unrouted Questions And Concerns

Status: active reusable staging reference
Scope: temporary capture of reusable questions or concerns whose correct owner, trigger or planning moment is not yet clear.

## 1. Purpose

A useful question should not disappear merely because its final documentation home is unknown.

This file is a staging area, not a permanent fourth question taxonomy.

```text
useful concern appears
  → capture it here when routing is genuinely unclear
  → use it in real analysis/planning
  → learn its responsibility / trigger
  → move it into the correct owner
  → remove the duplicate or leave only a redirect when useful.
```

Do not place a question here when an existing owner already clearly owns it.

## 2. Record Shape

A compact record may contain:

```text
ID:
Question / concern:
Why it may matter:
Possible owners:
Possible trigger / moment:
Current routing status:
Notes from use:
```

The exact fields are optional. Preserve the question and the reason it is worth remembering.

## 3. Routing Rules

- Moment-specific observation prompts belong in [`Observation Flow And Moment Prompts`](observation-flow-and-moment-prompts.md) when the main value is knowing **when** to notice them.
- Structural questions belong in [`Game Structure Analysis`](game-structure-analysis.md).
- Experience conditions, indicators and anti-experience checks belong in [`Player Experience And Anti-Experience`](player-experience-and-anti-experience.md).
- Visual situation-to-requirement questions belong in [`Visual Design Analysis And Planning`](visual-design-analysis-and-planning.md).
- Stable definitions and principles belong in the relevant principle-and-terminology owner rather than here.
- A project-only question belongs in the project planning owner unless repeated use demonstrates reusable value.

## 4. Current Staged Questions

### UQ-001 — Closest Imagined Existing Visual / Experience Reference

**Question / concern:**

If the planned game already existed, what existing game, film, interface, physical environment or other visual source does its presentation feel closest to — or what source do you imagine when thinking about it?

Useful follow-ups:

- What exactly seems similar?
- What do you want to preserve?
- What must be different?
- Is the similarity visual language, overall vibe, target experience, camera, information presentation, genre signal, production approach or something else?
- Which existing comparison would be undesirable?
- If the result became too similar, what would make it feel like copying?
- Which change could preserve the desired value while creating a distinct identity?

**Why it may matter:**

The answer can reveal an implicit visual baseline, experience reference, market comparison or production reference before formal art direction exists.

**Possible owners:**

- Visual Design Analysis And Planning;
- Reference First / concrete reference analysis;
- Audience / market comparables;
- Player Experience.

**Possible trigger / moment:** unresolved. Useful when the project direction is visually abstract, when references are too generic, or when candidate art directions lack a clear anchor.

**Current routing status:** staged cross-cutting question. Re-evaluate after practical use in one or more projects.

## 5. Do Not

- Do not turn this file into a backlog of every unanswered project question.
- Do not duplicate complete question sets from canonical owners.
- Do not leave a question here after its reusable responsibility becomes clear without a reason.
- Do not treat a staged question as a mandatory step in every analysis.

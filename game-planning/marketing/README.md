# Game Planning — Marketing

Status: active game-planning direction owner
Scope: audience, positioning, comparison-set, purchase-fantasy, market-legibility and proof planning as part of game/Concept development.

## 1. Responsibility

Marketing is treated as a planning direction connected to the actual game, not as a wrapper added after design is finished.

Stable reusable principles:

- [`../../principles/audience-is-part-of-the-game-principles-and-terminology.md`](../../principles/audience-is-part-of-the-game-principles-and-terminology.md)
- [`../../principles/market-and-platforms-principles-and-terminology.md`](../../principles/market-and-platforms-principles-and-terminology.md)

Exact platform behavior may change and should be rechecked when operationally relevant.

## 2. Planning Surfaces

Ask proportionally:

```text
Who is the intended audience?
What is the purchase fantasy?
Which games form the useful comparison set?
What makes the game legible quickly?
Why choose this game rather than the comparison set?
What is the differentiator after concrete gameplay is understood?
What store/trailer/demo/playable proof demonstrates the real promise?
What expectations would positioning create?
Can the actual game satisfy those expectations?
What market evidence could change the Concept or positioning?
```

## 3. Relationship To Game Analysis

`game-anal/` contains concrete analysis of existing games and can provide comparison/reference evidence.

```text
existing-game analysis
→ comparison / audience / proof evidence
→ Marketing planning
→ affected Concept / project owners.
```

Concrete analysis is evidence; it does not automatically decide positioning.

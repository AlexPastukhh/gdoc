# Game Planning — Brainstorming

Status: active working game-planning brainstorming direction; deeper specialized techniques remain under development
Scope: how answer generation is applied to game-planning Concepts, units, Low-Level Elements, Experience, Visual, Marketing and other planning needs.

## 1. Responsibility

This area exists because game-planning brainstorming is not only generic creativity. The useful method depends on **what planning responsibility needs answers** and what must be preserved.

Current high-level creative synthesis remains owned by [`../../game-creation-workflow.md`](../../game-creation-workflow.md). This direction will develop more explicit techniques as real use validates them.

## 2. Basic Route

```text
Need / unresolved owner question
→ bounded Brainstorm Prompt when useful
→ generate several materially different answers
→ Idea Variants
→ local evaluation
→ integrate promising answers at the real planning scale
→ wider evaluation / combinations
→ selected/current conclusion reconciled into the real owner.
```

Current answer sources already supported by the creation workflow include:

```text
independent thought;
reference borrowing;
reference transformation;
recombination;
novel brainstorming;
hybrid approaches.
```

These are answer-source families, not yet a complete technique catalog.

## 3. Planning-Need Applications

Future/working techniques may be developed specifically for:

- whole-game Concept generation/transformation;
- Situation / Event / Execution / Loop / Dynamic / Scenario questions;
- Low-Level Elements inside planning units;
- Experience / Motivation problems;
- Visual problems and realization alternatives;
- Marketing / positioning / comparison questions;
- reference transformation and combination;
- constraint-driven, causal, inversion/opposite or other useful methods after real validation.

Do not create a separate technique file merely because a possible technique name can be imagined.

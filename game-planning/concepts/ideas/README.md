# Concept Ideas

Status: active exploratory workspace navigation
Scope: standalone whole-game Concept Ideas and Brainstorm Prompt workspaces whose primary question belongs at Concept scale.

Use the normal Idea boundary:

```text
Concept Idea / Prompt
→ Idea Variants / evidence / evaluation
→ possible Concept record or Concept revision after review

Idea
≠ accepted game direction.
```

Prefer one primary file per independently useful standalone Idea or bounded Brainstorm Prompt. Keep Idea Variants inside their Prompt workspace until independent ownership is actually useful.

Do not put every idea from every game here. Once a question is clearly specific to a concrete game's gameplay, Visual, Marketing, Scenario or another owner, use that nearest owner-local `ideas/` workspace.

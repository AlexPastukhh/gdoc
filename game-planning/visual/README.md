## 2. Working Surfaces

Useful questions may include:

```text
What must the player notice / distinguish / understand?
What desired Experience/perception should the visual layer support?
What visual identity makes the Concept legible?
What information/state changes need visual proof?
What references serve which responsibility?
What production/asset burden follows from the proposed realization?
```

Visual work can be Concept-level or tied to a Situation, Execution, Loop, Scenario Beat or another concrete context.

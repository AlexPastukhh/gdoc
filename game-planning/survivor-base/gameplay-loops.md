## 2. Candidate Gameplay Loop — Tactical Raid And Reintegration

**Status:** inference / decision candidate derived from current source meaning; not explicitly accepted as the final Loop formulation.

### Function / player value

Outside operations should connect to the same living base system rather than form an independent second game. Preparation, tactical execution, return and reintegration are useful to review together because their consequences feed later base needs, knowledge and risk.

### Candidate recurrent causal process

```text
base need / capability target
→ strategic target and squad preparation
→ travel / site entry
→ direct tactical exploration / contact
→ loot / evidence / injuries / contamination
→ return to perimeter
→ own-raid intake / decon / medical assessment
→ integrate resources / evidence back into base
→ consequences change production, knowledge and future risk
→ later base need / opportunity creates another outside-operation decision.
```

### Why these parts may form one Loop

The useful causal continuity is not merely that all phases concern a raid.

```text
base state creates the reason to leave
→ preparation changes what is possible outside
→ outside results create people/object/evidence state
→ reintegration changes the operating base
→ the changed base changes later needs and opportunities.
```

If implementation makes preparation and reintegration largely irrelevant to the tactical site, this candidate may fail the functional-coherence test and should be revised rather than preserved by name.

### Important current interfaces

```text
production / capability need
↔ target selection and preparation;

people / equipment / tactical control
↔ site execution;

injury / contamination / objects / evidence
↔ return intake and sanitation;

new resources / evidence / losses
↔ later production, policy, knowledge and risk.
```

The current direction also expects raid squads and some base-response squads to share tactical command language. That relation does not by itself prove Loop membership.

### Current questions

- Which concrete Situation Types recur strongly enough to define the Loop rather than leaving this as one broad operation chain?
- What rules/state make outside operations recur?
- Which state is carried from preparation into the site and from the site back into base play?
- How often should the process recur before it becomes routine or a separate dominant game?
- Do decisions made **before** and **after** the tactical site matter as much as the fight itself?
- Does reintegration create enough meaningful consequences to make the return phase part of the recurrent causal process?
- Which Dynamics can repeated successful/failed raids contribute to?
- Which representative Scenarios best test whether the Loop is actually integrated with base operation?

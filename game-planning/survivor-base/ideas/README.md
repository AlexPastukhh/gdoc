## 1. Responsibility And Authority

This directory preserves independently useful project Ideas and scoped Brainstorm Prompt workspaces. One standalone Idea or one primary planning question/Prompt has one primary record file. Idea Variants stay inside their Prompt file until independent ownership is actually useful.

```text
Design Direction folder / README
  = navigation + shared exploration context;

standalone Idea file
  = one preserved spontaneous / source Idea;

Prompt file
  = one bounded answer-seeking workspace
    + its Idea Variants / evaluation / conclusion.
```

Preserve the reusable boundary:

```text
Idea
≠ decision
≠ accepted project meaning.
```

When an Idea becomes explicitly accepted, reconcile it into the real owner(s) whose responsibility it changes. Back-write the legacy Draft only when migration compatibility/provenance responsibility requires it.

When an embedded content example becomes useful as an independently reviewable playable/content unit, it may be copied or moved to [`../content-premises.md`](../content-premises.md). Hybrid examples remain inside their Idea record until that split is useful.

Use the proportional workspace structure from [`../../../game-creation-workflow.md`](../../../game-creation-workflow.md): source/Need, Prompt where one exists, Idea Variants, evidence, Local Evaluation, relations, integration findings and Current Conclusion. Do not create empty fields merely to satisfy a template.

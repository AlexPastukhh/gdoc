## 1. Responsibility

This directory owns Survivor Base-specific audience/positioning/comparison/purchase-fantasy/market-legibility/proof work when it has independent review/change responsibility.

Marketing findings can reveal a Concept problem, but they do not silently rewrite gameplay/project owners. Reconcile any design-changing conclusion into the affected real owner after review.

## 2. Current Starting Questions

Current work should establish proportionally:

- intended audience / relevant player expectations;
- useful comparison set and why each comparison matters;
- purchase fantasy / concise promise;
- central differentiator after the actual gameplay becomes concrete;
- what screenshots/trailer/demo/playable proof can demonstrate the real promise;
- which strong gameplay properties are difficult to communicate;
- which attractive-sounding claims are not supported by current play;
- important market/platform assumptions and evidence gaps.

## 3. Relationship To The Current Concept Validation Pass
